# 夹爪性能测试与控制参数（2026-11-04）

本次用户重新授权开合性能测试，说明已手动张开至最大，并确认空载、活动区清空且平放或稳固固定。实测位置约10，符合接近张开端。完成通信测量和两次有界启动诊断；反应时间、速度、实际夹持力和定位精度没有获得合格的机械运动结果，不写成“测试通过”。生产适配器的运动锁保留。

## 1. 当前实机和控制原理

U2D2 USB转RS-485，WSL `/dev/ttyUSB0`，协议DYNAMIXEL2.0，ID1，2Mbps。PING返回RH-P12-RN旧版35073、固件25，不能套用RN(A)寄存器表。供电约24.2V，温度43℃，硬件错误寄存器0。

当前模式5是“电流限制的位置控制”：上位机发目标位置、速度上限、加速度、电流上限；夹爪自己的控制器根据编码器反馈运行位置PID及电流控制，最终驱动电机。上位机不直接生成电机PWM，也不能把串口写入确认当作动作完成。另有模式0，直接控制电流/方向，但本轮没有切换模式、没有改EEPROM、没有改PID或升级固件。

| 参数 | RN地址/字节 | 含义、单位及实机值 |
|---|---|---|
| 工作模式 | 11 / 1 | 当前5；模式0为电流控制，5为电流限制的位置控制 |
| 电机使能 | 562 / 1 | 0关闭，1开启；仅切换使能也可能产生运动，不能认为只有写开合目标才会动 |
| 目标位置 | 596 / 4 | 数值较小张开、较大闭合；设备配置范围0～1150；不是毫米 |
| 目标速度 | 600 / 4 | 每计数0.114rpm；诊断设置4，即0.456rpm；0表示关闭速度轮廓、使用最大速度，**不是停机** |
| 目标电流 | 604 / 2 | 官方每计数约4.02mA；模式5下是电流上限，模式0下是目标电流；诊断设置25，即约100.5mA |
| 目标加速度 | 606 / 4 | 每计数214.577rev/min²；诊断设置1，设备上限255；未做实际加速度验证 |
| 实测位置 | 611 / 4 | 编码器位置计数，有符号读取；需测量开口宽度后才能建立计数→毫米关系 |
| 实测速度 | 615 / 4 | 有符号，按官方单位每计数0.114rpm；不是已标定夹口mm/s |
| 实测电流 | 621 / 2 | 有符号，按官方单位每计数约4.02mA；本轮发现启动时异常读数，不能直接折算牛顿 |
| 电压、温度 | 623 / 2，625 / 1 | 0.1V/计数，1℃/计数 |

在NeuroFusion框架中，当前独立夹爪一维物理动作表示绝对闭合比例0～1，映射到设备位置限；速度和电流限制属于驱动配置，当前动作头并不同时预测它们。实际夹爪反馈映射到q[15]；网络输出仍不发送到实机。

## 2. 两次启动诊断及停止原因

第一次设置目标位置10、目标速度4、电流上限25、加速度1，逐项读回一致，再短暂使能。首次30字节连续寄存器采样显示目标位置仍10、速度设置仍4、电流设置仍25，**实测电流原始值为-249**，按表换算约-1.001A。这与100.5mA的设置明显不符，触发保护。

- 使能请求到首次反馈返回约3.982ms。
- 使能请求到关闭使能收到确认约5.992ms。
- 这些是主机侧诊断/停止通信时间，**不是电机机械反应时间**。
- 关闭后已确认使能0；当时位置约8、电流0、错误0。

随后目标电流设0、维持当前位置目标，使用SDK直接两字节读取电流，排除仅由连续块字段解析造成的误解。反馈原始值先-2再-8，按表约-8.04～-32.16mA；位置8→6→4，触发约28mA门限并关闭。这些小电流可能包含偏置、噪声或瞬态，不能单凭它定性硬件损坏；但整体不足以证明启动时电流限制可靠，所以没有提高电流、放宽保护或继续跑闭合。

本轮未发现目标寄存器被重置，不能继续把上次意外张开归结为“目标自动归零”。此前意外运动与本次电流异常的根因均未确定；当前证据支持保留运动锁，先用官方Wizard进行独立读数验证，再检查供电/接线/固件及实际电流。

## 3. 可以可靠给出的实测结果

电机关闭状态下，100次交替写入目标位置10/11并读回，全部一致；使能始终0，没有做机械动作。

| 项目 | 中位数 | 95%分位 | 最慢 |
|---|---:|---:|---:|
| 发写指令→收到设备确认 | 1.984ms | 3.916ms | 18.946ms |
| 发写指令→再次查询并读回目标 | 3.989ms | 6.152ms | 41.588ms |

这包括Python调用、WSL、USB转发、FTDI、RS-485以及回复，不是纯电机控制器时间。100次样本规模小，不构成最坏时延保证。最慢单次确认约19ms，不能仅凭约2ms中位数宣称100Hz硬实时控制已达标。

静止位置100次读取全部10计数，只能说明这一次静止反馈稳定，**不是定位误差为零**。

| 用户要求的指标 | 本次结论 | 获得有效结果所需条件 |
|---|---|---|
| 实际反应时间 | 未测得；只有通信确认时间 | 启动行为可靠后，明确动作阈值，记录目标发送与首次实测移动；物理起动最好用高速视频/外部传感器交叉验证 |
| 实际运动速度 | 未测得 | 多个安全行程及速度档，持续采位置；计数/s可先测，mm/s需要夹口几何标定 |
| 实际夹持力 | 未测得，无测力计数据 | 测力计/压力传感器、固定接触位置与开度；采电流和实测力做标定；不能用额定最大力按电流比例相乘 |
| 定位精度/重复性 | 未测得 | 正反方向反复到相同目标；测稳态位置误差、重复性、回差；外部卡尺/位移测量才可给夹口mm精度 |

官方规格列最大闭合速度75mm/s、最大夹持力170N及0.088°角度规格。这些不是本机实测结果，也不能当作工作中可保证的夹口精度或安全夹力。
