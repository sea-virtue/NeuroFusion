# 受控滑移的真机 BC 采集方案

日期：2026-11-11。状态：采集设计，尚未实现教师控制器、动作同步录制或 BC 数据导出，未进行实机运动。本方案以用户选定的 Gloumakov et al. 2024 为方法参考；它不是原作者代码或已验证复现。

## 1. 研究范围与方法来源

先固定机械臂，仅学习夹爪一维的允许滑动、提前制动和持稳；后续再扩展机器人鱼或转移。无准确夹爪/摩擦模型时，可用真机控制器产生示教，再做 BC；不需要先建完整仿真，但仍需要可用教师、可靠运动测量和夹爪响应标定。

原论文 IV-E 的再抓取演示以约 30 ms 信号估计运动后预测开口时长，并补偿约 120 ms 电机响应。原 SlipTack 的电容幅值与加速度映射不适用于 Speck/GelNeuro，不能直接迁移系数。计划借鉴其任务与教师框架，而非声称直接运行原方法。

原文：https://escholarship.org/content/qt9k30z443/qt9k30z443.pdf
代码来源核查：`third_party/sliptack2024.reference.json` 与 `third_party/sliptack2024-reference/README.md`。

## 2. 先分开运动真值标定与动作示教

第一批：用独立测量记录物体相对夹爪的位移、速度与接触信号。可用不进入策略视野的侧面高速相机加标记，或合适的位移传感器/编码机构。测量频率与延迟要覆盖实际制动过程；编码机构若改变载荷/摩擦，必须记录。固定夹爪时，仍要检查物体旋转、传感器/装置运动造成的相对位移误差。

这批数据用来训练/标定事件运动估计器。外部标记由评估相机观察，不要求 RGB 策略看到；GelSight 位于另一侧，也不能直接当事件侧运动或力真值。事件多只能说明光学变化，不能直接换算速度或位移。

第二批：由已验证的教师在真机上完成目标距离滑动，并录制动作。单纯手动擦动触觉、只录视频或把低频操作插值，都不能提供正确的高速动作示教。

## 3. 教师的两个选择

A. 外部测量辅助的教师（建议作为首版数据来源）：在线因果读取位移/速度，结合本机响应标定决定何时制动。学生只读其部署时实际具备的事件、GelSight、夹爪反馈、目标及动作历史。外部运动状态属于教师额外观测，独立存储，不混入学生输入。若同样学生历史可能对应不同正确动作，须增加可用历史/观测或缩小任务，不能指望 BC 解决不可观测性。

B. 论文启发的触觉教师：先把事件特征标定成可用的运动估计，再预测制动时机；需实测误差、材料迁移及机械响应。可先用 A 监督 B 的运动估计。原文系数和 SlipTack 传感器模型不直接搬用。

两种教师都先完成可重复闭环验证后再规模录制。教师动作经过同一执行接口限幅，记录覆盖、接管、保护动作及原因，不把所有成功片段自动视为最优示教。若教师仅按固定时间夹紧，学生可能只学定时器；必须变化目标距离、初始接触、载荷/摩擦及滑动条件，并检验动作是否随实际运动变化。

## 4. 单回合流程

1. 填写物体/表面/载荷/采集批次与初始接触，指定目标位移和容差；设置相对位移零点。学生必须知道任务目标和零点约定。
2. 记录稳定接触基线，并在统一主机单调时钟下记录传感器、教师、动作及外部测量的接收/可用时刻。
3. 教师减小闭合量使物体滑动，以最新可用证据决定何时制动。不要等待“估计位置正好到目标”才收紧。
4. 制动后继续记录到稳定，用独立测量计算最终位置、最大超调、停止时间与是否失去接触；保存失败/异常，不覆盖。
5. 每轮重新建立接触并改变条件，先做小批诊断回合检查时钟、信号及标签，再依据学习曲线扩大采集。

局部简化可用 `剩余距离 <= 速度 × 延迟 + 制动距离 + 余量` 作为制动触发候选；各项必须在本机标定，这不是原论文逐式复现。它只适用于已明确方向/运动条件，不能用自由落体或恒定加速度假设代替所有接触动力学。传感、调度、通讯及电机共同决定有效延迟。高频事件或高速写寄存器都不保证同频机械响应。

## 5. 每回合需要保存的内容

| 类别 | 最低内容 |
|---|---|
| 任务 | episode_id、目标位移/容差、初始零点、物体/材质/载荷/批次、教师/标定版本 |
| 原始传感 | 原始事件及设备时间、GelSight 原始帧、主机接收与实际可用时间；RGB 若参与也同期记录 |
| 执行反馈 | 实测位置/速度/电流及时间，模式、限幅、有效性；电流未标定不能称夹持力 |
| 动作标签 | 教师期望动作、限幅后实际下发动作、单位/方向/动作生效区间、生成/发送/ACK 时间及 command_id |
| 机械响应 | 后续实测位移/开合响应；不要把 ACK 称动作完成，也不要用实测位置冒充命令标签 |
| 教师额外观测 | 外部位移/速度、采样与可用时间、估计/滤波方式及质量，独立于学生输入保存 |
| 质量/结果 | 人工接管、保护覆盖、采集积压/丢失、终止原因、停止误差/超调/失落、示教质量标记 |

当前物理适配器动作语义是一维绝对闭合比例 0..1（0 为设备最小位置端、1 为最大端），不是毫米、力或每步增量。应保留原始寄存器数值和映射版本。先按此接口定义动作；若以后改为电流控制，需要独立验证并升级 schema。

BC 配对取“动作决策当时已可用的输入 -> 该控制周期实际下发的教师动作”，同时保留未限幅意图及覆盖原因用于筛选。不能把未来帧、事后平滑的未来信息或机械响应后的状态配给过去命令。观测年龄和动作历史要保留。标定时钟映射及采集时延，不用把不同设备原始时间直接相减。若反馈只有查询时刻，披露其时序不确定性。

## 6. BC 与验证

输入包含目标，动作覆盖稳定保持、减小闭合、滑动期间的保持和制动等阶段；不能只保留成功结束时的夹紧命令。按控制周期和有效时间构造样本，不把事件数量当样本权重；针对少数制动窗口可做明确的阶段采样/加权，并保持自然分布评估。

按完整回合划分训练/验证/测试，并保留未见目标、载荷/表面/批次；不能随机切相邻帧。独立测试同时对比固定时间、帧式反馈、简单事件反射和完整快慢策略，保证相同动作权限与限幅。输出停止误差、最大超调、失落率、响应分段时间，必要时测独立力/形变。

纯 BC 先检验能否接近教师，不预设超过教师。若学生滚动后进入示教未覆盖状态，后续可用同一教师在线纠正/补标学生访问的状态；这属于额外的数据聚合步骤，需单独记录，当前未实现。
